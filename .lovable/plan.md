## 목표
참가자가 잘못 입력한 닉네임(별명 → 본명)을 진행 중에도 안전하게 수정할 수 있게 한다. 현재 접속 중인 다른 선생님들의 세션·산출물·진행 상황에는 영향이 없어야 한다.

## 왜 안전한가 (현재 구조 확인)
- 모든 산출물 테이블은 `user_id`(UUID)로 연결되어 있음 — 닉네임은 표시용 라벨일 뿐, FK가 아님.
- `app_users.nickname`만 갱신하면 됨. 좌석/아바타/체크포인트/PRD/슬라이드/미션/메시지 모두 그대로 유지.
- 재입장(`checkExistingUser`)은 코드+닉네임으로 매칭 → 변경 후에는 새 닉네임으로 재입장해야 함. 이 부분은 localStorage도 함께 갱신해서 즉시 반영.

## 변경 사항

### 1. 서버 함수 추가 (`src/lib/session.functions.ts`)
`renameNickname({ userId, nickname })` 신설:
- 본인(`userId`) 레코드만 수정 (다른 사람 변경 금지).
- 같은 세션 내에 동일 닉네임이 이미 있으면 거절 (`"이미 사용 중인 닉네임입니다"`).
- 성공 시 `app_users.nickname` 업데이트 → 새 닉네임 반환.
- 기존 `enterSession` / 다른 함수는 손대지 않음 → 진행 중인 세션 영향 0.

### 2. 홈 화면 UI (`src/routes/home.tsx`)
명찰(Nametag) 옆에 작은 "이름 수정" 버튼 추가:
- 클릭 시 인라인 입력 + 저장/취소.
- 저장 성공 시 `writeStoredSession`으로 localStorage의 nickname만 교체 (userId/sessionId/role 유지 → 재로그인 불필요).
- 토스트로 결과 안내.

### 3. (옵션) 강사 대시보드에서 대신 수정
강사가 개별 참가자 이름을 대신 고쳐줄 수 있는 버튼을 참가자 리스트에 추가할지 여부 — **기본은 미포함**. 원하시면 알려주시면 추가합니다.

## 영향 범위
- DB 스키마 변경 없음 (마이그레이션 불필요).
- 기존 접속자: 페이지 새로고침·재로그인 요구 없음. 명찰 표시가 즉시 갱신됨.
- 강사 대시보드/2D 사무실 뷰: 다음 폴링(수 초 내)에서 자동으로 새 닉네임 표시.
